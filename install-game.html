Instalar jogo

O JogaHub abre a página oficial do jogo. A instalação é concluída pelo próprio navegador, porque um site não pode instalar outro PWA diretamente.

Abrir jogo para instalar ← Voltar ao JogaHub

Se a opção de instalar não aparecer, esse jogo pode não ter PWA configurado ou o navegador pode exigir que você abra o jogo e use o menu de instalação.
